# v0.17.2: First live Jev results and preserved follow-up diagnostics

Repository release: v0.17.2 (2 October 2026, America/New_York). Current paper:
v0.17.0. This is a software and synthetic-experiment results release, not a revised
paper, independent validation, public-case finding or change to released TAE
conclusions. Earlier release tags, manifests and paper assets are unchanged.

## Included

- A separate live bridge for the frozen evidence-v2 corpus, pinned to Jev 1.13.0
  and TypeSafe SDK 0.7.1, with a complete prospective schedule and no retries.
- First live run: all 282 requests attempted; 260 valid, 22 invalid, no transport
  errors or interruptions. All responses reported jev-1.13.0. Of 4,962 scheduled
  determinations, 4,500 are valid under the frozen response rules.
- Primary reconstruction agreement: 198/231 valid determinations (85.7%), with
  231/252 coverage (91.7%). Primary authority agreement: 11/16; compositional
  holdout agreement: 110/126. These are authored synthetic reference agreements.
- Primary mutation exact deltas: 7/9 evaluable pairs. Nuisance choice changes:
  7/39 evaluable pairs out of 48 scheduled. Repetitions and absolute agreement are
  reported alongside pair metrics; no best-run selection or majority replacement.
- A 855-file raw-evidence archive, hash manifest, full per-construct metrics,
  confusion matrices, recalls, Brier scores and credential-free saved-run verifier.
- Post-output examination of probability-sum failures and partial-state disagreements.

## Unresolved findings and review boundary

Twenty-three distributions in 22 requests sum to approximately 0.99. The frozen
whole-request rejection rule excludes 462 determinations; no normalization or
subanswer recovery was applied. Rounding is a possible explanation, not an
established provider diagnosis. Partial-state cases frequently receive unsupported
judgments; model, question, construct and reference explanations remain unresolved.

All 1,079 disagreement/invalid-determination records remain open UNRESOLVED, with
their original and dated v2 forms preserved. The author accepted the results and
authorized merge and release; this does not constitute independent review or
close the original two-reviewer adjudication route. AI assistance and prior
design exposure are disclosed. No new inference was used for follow-up diagnostics.

## Reproduce

```sh
python -B -m experiments.jev.live_results_v1.verify
python -B -m experiments.jev.live_followup_v1.analyze --check
python scripts/verify_repository_release.py --ref v0.17.2
python scripts/validate_repository.py
```

The first two commands analyze saved data only. Core validation remains
credential-free and deterministic. Live calls are not part of CI or reproduction.

`v0.17.2-manifest.json` hashes the complete tracked snapshot except itself. The
release TAR is exported from the tagged commit; SHA256SUMS covers attached assets.
The manifest is anchored by Git history, not an independent registration service.
The standalone verifier continues to validate v0.17.1 against its unchanged tag.

Read `experiments/jev/live_results_v1/REPORT.md` and
`experiments/jev/live_followup_v1/README.md` for complete denominators and limitations.

post-output amendment. No revised experiment or new paper DOI is included.
